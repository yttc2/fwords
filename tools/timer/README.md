# Fwords 独立计时器

把背单词 App 里那套计时机制剥出来，做成一个双击就能用的桌面计时器。**不带词库、不带学习功能，只有计时。**

## 直接用

双击 `D:\Fwords\dist\Fwords计时器.exe`。单文件 exe（11 MB），拷到别的电脑上也能直接跑，不需要装 Python 或 Java。

## 界面

```
        Fwords 计时器                ● 运行中

              12:34
     净学习时长 · 暂停与离开窗口都不计入

      ╭─────╮          ╭─────╮
     │ 03:12 │        │ 21:45 │        ← 环形倒计时，剩多少一目了然
     │  剩余 │        │  剩余 │
     ╰─────╯          ╰─────╯
    T2 · 每 5 分钟   T3 · 每 30 分钟

   [开始] [重置]  ☐ 窗口置顶
```

## 功能

| 元素 | 说明 |
|---|---|
| **大数字** | 净学习时长正计时。暂停时不走，切后台时不走 |
| **T2 环** | 每 5 分钟一次回顾节点，默认值可改（1–180 分钟） |
| **T3 环** | 每 30 分钟一次，默认值可改（1–600 分钟） |
| **到点提示条** | 橙色条 + 响铃。**只提示不打断**，不会突然弹窗抢你注意力 |
| **窗口置顶** | 默认开启，边背边看不会被别的窗口盖住 |
| **自动保存** | 每秒存一次，关掉窗口进度不丢 |
| **快捷键** | `空格` = 开始/暂停，`R` = 重置 |

两个可选开关：
- **到点响铃** —— 到点时响两声（Windows 系统音，不外放文件）。
- **到点后自动暂停** —— 勾上以后到点会停住等你确认，适合严格卡 5 分钟休息一次。

进度存在 exe 同目录的 `timer-state.json`。放系统目录没写权限时自动转到 `%APPDATA%\FwordsTimer\`。想清零重来，删掉这个文件即可。

## 和App 里的计时保持一致的约定

这几条是从 `demo/app.js` 原样搬过来的，别随便改：

- **时间轴只有一条**：净学习时长。不用墙上时钟，所以暂停的时间天然被排除。
- **用时间差累加，不用计数器**：`perf_counter()` 进出差值。后者在卡顿时会漂移。
- **单次 tick 间隔 > 700ms 就丢弃**：切后台/主线程卡死的那段时间不计入。所以你切走 10 分钟回来，不会发现「早该回顾了」。
- **T3 到点时把 T2 一起复位**：T3 的窗口在集合意义上包含 T2，不一起复位的话会立刻重复弹一次。
- **软触发**：到点只提示，不自己跳转。

## 开发

源码 `tools/timer/timer.py`，单文件、无第三方依赖。

```bash
# 逻辑断言（36 项，不需要显示器）
tools/.venv-timer/Scripts/python.exe tools/timer/timer-test.py

# GUI 冒烟（30 项，真窗口 + alpha=0 不弹前台）
tools/.venv-timer/Scripts/python.exe tools/timer/timer-gui-test.py

# 打包
cd tools/timer && ../../tools/.venv-timer/Scripts/python.exe -m PyInstaller \
  --noconfirm --clean --onefile --windowed --name "Fwords计时器" \
  --distpath ../../dist timer.py
```

打包环境用 `tools/.venv-timer`（基于 anaconda Python 3.13.9建的 venv）——**必须用它而不是 WorkBuddy 托管的 Python**，后者没编译 tkinter，打出来的 exe 启动就崩。
